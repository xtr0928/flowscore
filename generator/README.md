# Pipeline Canvas · 可视化管线编排器

> **一句话定位**：零依赖、单文件的可视化管线编排器——双击 `index.html` 即可用，无需安装、无需构建、无需联网。

---

## 快速开始

无需任何安装步骤：

```
双击 index.html，浏览器打开即可使用
```

所有功能在本地运行，数据保存在浏览器本地，不上传任何服务器。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 画布拖拽连线 | 在画布上自由拖拽节点、通过端口拖拽连线，构建管线拓扑 |
| 节点字段配置 | 选中节点后在右侧面板编辑字段，表单由 schema 驱动自动生成 |
| 双文件导入导出 | 管线（`.pipeline.json`）与节点数据（`.nodes.json`）分离，可分别导入导出 |
| 版本兼容提示 | 打开高版本文件或结构不兼容时，给出明确中文提示而非静默失败 |
| 自动保存 | 编辑内容自动保存到浏览器本地存储，意外关闭后可恢复 |
| 中文界面 | 全部界面、提示、错误信息均为中文 |

---

## 目录导航

```
.
├── index.html          # 单文件主程序（唯一必需文件）
├── schema/             # 节点与管线格式定义（JSON Schema），驱动表单与校验
├── samples/            # 示例管线与示例节点数据，可直接导入体验
├── docs/               # 详细文档（见下方文档索引）
└── tests/              # 静态测试页与用例，验证核心逻辑
```

- **schema/**：定义节点类型、字段约束与文件格式版本，程序据此渲染配置表单。
- **samples/**：提供开箱即用的示例文件，用于演示与回归验证。
- **docs/**：用户与开发文档，见下方索引表。
- **tests/**：不依赖测试框架的静态测试页面，浏览器打开即运行。

---

## 静态部署（三行说明）

1. 拷贝 `index.html` 到任意静态站点目录；
2. （可选）拷贝 `schema/`、`samples/` 目录以便加载格式定义与示例；
3. 通过 HTTP 访问该文件即可，无需服务器端组件。

> 本地使用也可直接双击 `index.html`，以 `file://` 协议运行。

---

## 边界声明

**第一阶段不调用真实模型。** 本工具仅负责管线的可视化编排、配置编辑与文件的导入导出，不连接任何推理后端、不执行任何真实模型调用。文件格式设计已为后续接入执行引擎预留扩展空间。
