XTR 领域层浏览器测试（零依赖）

README / 使用说明：本页通过隐藏 iframe 加载 ../index.html，在 iframe 加载完成后访问 iframe.contentWindow.XTR 上的领域层接口（model / validate / compat / graph / io）执行断言。
因 file:// 协议下 iframe 同源访问与 fetch 在部分浏览器受限，建议用本地静态服务器打开本页： 在项目根目录执行 python -m http.server，然后访问 http://localhost:8000/tests/test.html。测试用例来自 tests/cases/graph.cases.json、tests/cases/validate.cases.json、tests/cases/compat.cases.json。
