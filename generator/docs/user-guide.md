## 开始之前：装好并打开软件

1. 确认软件已经安装并启动（桌面双击图标，或按项目 README 中的启动命令运行）。

3. 建议先看一遍下面的 [界面导览](#界面导览五个区域各是干什么的)，认识一下每个区域，再开始动手。

## 界面导览：五个区域各是干什么的

> 截图占位：软件主界面总览图，五个区域用彩色框和序号标出。

整个界面分成五个区域，从上到下、从左到右分别是：

### 1. 工具栏（顶部一排按钮）

> 截图占位：工具栏放大图，每个按钮下方标注名称。

工具栏上放着最常用的按钮，主要包括：

| 按钮 | 作用 |
| --- | --- |
| 新建 | 清空画布，从零开始画一条新管线 |
| 打开 | 载入之前保存的管线文件（`.pipeline.json`） |
| 导出管线 | 把你画的管线保存成一个 `.pipeline.json` 文件（给别人用、或交给程序执行） |
| 导出布局 | 单独保存「节点摆在哪里、窗口多大」这类外观信息 |
| 撤销 / 重做 | 后悔药：撤销上一步操作 / 恢复被撤销的操作 |
| 校验 | 检查管线有没有画错（比如忘了连线） |
| 运行 | 实际执行这条管线（需要渠道已配置好） |

### 2. 节点面板（左侧列表）

> 截图占位：节点面板放大图，列出「输入」「模型调用」「输出」三类节点。

这里陈列着所有可用的「积木」。目前有三类：

- **输入节点**：管线的起点，用来放原始材料（比如一段文章文字）。
- **模型调用节点**：管线的中间环节，负责调用 AI 模型（比如 DeepSeek）来处理文字。
- **输出节点**：管线的终点，负责把结果保存成文件（比如 `.md` 文本文件）。

### 3. 画布（中间的大片空白区域）

> 截图占位：画布上有三个节点和两条连线的示意图。

画布就是你的「工作台」。把积木拖到这里、摆好位置、用线连起来，一条管线就画好了。

- 画布可以无限延展，按住空白处拖动可以平移视角；
- 滚动鼠标滚轮可以放大 / 缩小画面。

### 4. 属性面板（右侧表单）

> 截图占位：属性面板放大图，展示一个模型调用节点的配置表单。

点击画布上的任意一个节点，右侧属性面板就会显示这个节点的「设置表单」。比如：

- 输入节点：在这里粘贴原文；
- 模型调用节点：在这里选渠道、选模型、填提示词；
- 输出节点：在这里选文件格式、起文件名。

**要点：改了属性面板里的内容后，记得点一下别处或按回车，改动就会立即生效并自动保存。**

### 5. 状态栏（底部细条）

> 截图占位：状态栏放大图，显示「已自动保存 · 3 个节点 · 2 条连线 · 就绪」等字样。

状态栏随时告诉你三件事：

- 现在的保存状态（「已自动保存」还是「正在保存」）；
- 当前管线一共有几个节点、几条连线；
- 最后一次操作的结果（比如「校验通过」或「导出成功」）。

## 五步画管线（手把手教学）

目标：画一条「输入一段文章 → 让 DeepSeek 总结 → 保存成 Markdown 文件」的管线。

### 第 ① 步：拖出输入节点，粘贴原文

1. 在左侧节点面板找到「输入」节点。
2. 按住鼠标左键，把它拖到画布中间的空白处，松开鼠标。画布上会出现一个新节点。

   > 截图占位：从节点面板拖拽「输入」节点到画布的动态示意图。

3. 用鼠标左键点一下这个节点，右侧属性面板会切换成它的设置表单。
4. 在「内容」输入框里，粘贴（`Ctrl+V` / `Cmd+V`）你想要总结的文章全文。
5. （可选）在「节点名称」里把它改名为「文章输入」，方便自己辨认。

> 截图占位：属性面板中已粘贴大段文字、节点改名为「文章输入」的样子。

### 第 ② 步：拖出模型调用节点，选渠道 DeepSeek，填提示词

1. 再从节点面板拖一个「模型调用」节点到画布上，放在输入节点的右边。
2. 点选这个新节点，在右侧属性面板中：
   - **渠道**：下拉选择 `DeepSeek`；
   - **模型**：选择 `deepseek-flash`（也可以选列表里你喜欢的其他模型）；
   - **提示词**：在提示词输入框里填入：

     ```
     请阅读以下文章，并生成一份结构清晰的 Markdown 摘要：
     {{input.text}}
     ```

     > 说明：`{{input.text}}` 是一个「占位符」，意思是「这里填入上一个节点传来的文章文本」。你不需要自己复制文章，程序运行时会自动替换。
   - （可选）把节点改名为「生成摘要」。

> 截图占位：模型调用节点的属性面板，渠道选了 DeepSeek，提示词里可见 `{{input.text}}`。

### 第 ③ 步：拖出输出节点，选 `.md`

1. 从节点面板拖一个「输出」节点到画布上，放在模型调用节点的右边。
2. 点选它，在属性面板中：
   - **格式**：下拉选择 `md`（Markdown 文本文件）；
   - **文件名模板**：填 `article-summary.md`（这是最终生成的文件名，可以自己改）；
   - （可选）把节点改名为「输出结果」。

> 截图占位：输出节点属性面板，格式为 `md`，文件名为 `article-summary.md`。

### 第 ④ 步：从端口拉线连接

现在画布上有三个孤立的节点，需要用线把它们串起来。

1. 把鼠标移到「文章输入」节点**右侧边缘**，会看到一个小圆点（这叫「端口」），鼠标靠近时光标变成十字。
2. 按住左键，从「文章输入」的 `text` 端口（文章文本）一路拖到「生成摘要」节点**左侧边缘**的 `text` 端口上，松开鼠标。两点之间出现一条线，说明连接成功。

   > 截图占位：从输入节点右侧端口拉线到模型调用节点的动态示意图。

3. 同样地，从「生成摘要」的 `result` 端口拉一条线到「输出结果」的 `content` 端口。

完成后，画布上应该是：`文章输入 → 生成摘要 → 输出结果`，共两个节点间连线。

> 截图占位：三个节点连成一线的完整画布截图。

**小提示**：连线有方向，只能从上一个节点的「出口」连到下一个节点的「入口」。如果连反了，线会自动弹回去。

### 第 ⑤ 步：点「导出管线」与「导出布局」

1. 点击顶部工具栏的 **「校验」** 按钮。如果状态栏显示「校验通过」，说明管线画得没问题；如果有错误，按状态栏提示修改。
2. 点击工具栏的 **「导出管线」** 按钮，在弹出的窗口中选择保存位置和文件名（例如 `my-first-pipeline.pipeline.json`），点保存。这个文件就是你的管线本体，可以交给别人或交给程序执行。
3. 再点击工具栏的 **「导出布局」** 按钮，保存一个布局文件（例如 `my-first-pipeline.layout.json`）。它记录了节点在画布上的摆放位置，下次打开时画面和你现在看到的一模一样。

> 截图占位：导出成功后状态栏提示「导出成功」的截图。

🎉 恭喜！你已经完成了人生第一条管线。如果想立刻看到成品，可以在配置好 DeepSeek 渠道后点「运行」，到 `output` 文件夹里找 `article-summary.md`。

## 导出与保存：你的成果去哪了

| 动作 | 产生的文件 | 里面是什么 |
| --- | --- | --- |
| 导出管线 | `*.pipeline.json` | 管线的完整定义：有哪些节点、怎么连接、各节点的设置 |
| 导出布局 | `*.layout.json` | 纯外观信息：节点摆放在画布的哪个位置、窗口大小 |
| 自动保存 | 软件自动写入（见下方 FAQ） | 你最近一次编辑的现场，下次启动时自动恢复 |

两个文件是**互相独立**的：管线文件给别人，别人打开后功能正常，但节点位置可能不一样；布局文件只影响外观，不影响功能。

## 常见问题（FAQ）

### Q1：为什么连不上线？

按顺序检查以下几点：

1. **方向反了**：线只能从左侧节点的「出口端口」拖到右侧节点的「入口端口」。检查你是不是从右往左连的。
2. **没对准端口**：松开鼠标时，必须让线的终点落在目标端口的小圆点上（端口会高亮提示）。落在节点身体上是连不上的。
3. **类型不匹配**：出口和入口的类型必须一致（比如 `text` 出口只能连 `text` 入口）。把鼠标悬停在端口上，会显示它的类型。
4. **重复连线**：两个端口之间已经有一条线时，不允许再连第二条。想换线，先点选旧线按 `Delete` 删除。

### Q2：为什么导出按钮弹错误？

最常见的原因是**管线没画完整**。导出前请确认：

1. 每个节点都不是「孤岛」——输入、模型调用、输出三类节点至少各有一个，并且全部被线连成一串；
2. 模型调用节点的渠道、模型、提示词都已填写，提示词中没有遗漏的 `{{` 或 `}}`；
3. 输出节点的文件名是合法的（不要包含 `/`、`\`、`:` 等特殊字符）。

建议先点工具栏的「校验」按钮，错误提示会告诉你具体是哪个节点出了问题。修正后再导出即可。

### Q3：自动保存的文件在哪？

软件会每隔一小段时间自动保存你的编辑现场，位置在：

```
（用户数据目录）/autosave/
```

具体路径可在底部状态栏的「已自动保存」字样上悬停查看（不同操作系统路径不同）。你**不需要**手动管理这些文件，它们只用于崩溃恢复和下次启动时自动恢复现场。想长期保存一条管线，请务必使用「导出管线」。

### Q4：如何恢复上次会话？

- **正常情况**：下次启动软件时，会自动弹窗询问「是否恢复上次的编辑现场？」，点「恢复」即可回到关机前的画面（节点位置、连线、所有设置都还在）。
- **软件崩溃 / 断电**：重新打开软件，同样会自动检测到自动保存文件并提示恢复。
- **想从头开始**：在恢复提示中点「不恢复」，或点工具栏的「新建」清空画布。
- **打开以前导出的文件**：点工具栏的「打开」，选择 `.pipeline.json`（如需还原节点位置，把对应的 `.layout.json` 放在同一文件夹里一起选择即可）。

### Q5：快捷键有哪些？

完整速查表见下文 [快捷键速查表](#快捷键速查表)。

### Q6：我不小心删错了节点怎么办？

按 `Ctrl+Z`（Mac 上 `Cmd+Z`）撤销，可以连续撤销多步。误删的连线同样可以撤销。

## 快捷键速查表

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Z` / `Cmd + Z` | 撤销上一步 |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | 重做（恢复被撤销的操作） |
| `Ctrl + C` / `Cmd + C` | 复制选中的节点 |
| `Ctrl + V` / `Cmd + V` | 粘贴节点（在文本框内则是粘贴文字） |
| `Ctrl + X` / `Cmd + X` | 剪切选中的节点 |
| `Delete` / `Backspace` | 删除选中的节点或连线 |
| `Ctrl + A` / `Cmd + A` | 全选画布上的节点 |
| `Ctrl + S` / `Cmd + S` | 立即触发一次自动保存 |
| `Ctrl + E` / `Cmd + E` | 导出管线 |
| `Ctrl + 鼠标滚轮` / `Cmd + 鼠标滚轮` | 放大 / 缩小画布 |
| `空白处拖动` | 平移画布（按住空白处整体移动视角） |
| `空格 + 拖动`（或按住滚轮拖动） | 平移画布 |
| `Ctrl + 空白处拖动` | 矩形框选节点 |
| `Ctrl + 0` / `Cmd + 0` | 画布缩放复位到 100% |
| `Esc` | 取消当前拖拽 / 取消选择 |
| `Tab` | 在属性面板的输入框之间逐个跳转 |

> 提示：Mac 用户把 `Ctrl` 换成 `Cmd` 即可，其余一致。

## 示例管线讲解：文章摘要管线

随软件附带一个现成的示例文件：`samples/demo-basic.pipeline.json`。你可以点工具栏的「打开」载入它，对照本节理解一条完整管线的样子。

### 这个示例做什么

输入一篇文章全文 → 调用 DeepSeek 模型生成结构化的 Markdown 摘要 → 保存为 `article-summary.md` 文件。它正是上文「五步画管线」所画的那条管线，可以当成标准答案对照检查。

> 截图占位：载入示例后画布的整体截图，三个节点横向排列，两条连线，属性面板展示「生成摘要」节点。

### 三个节点逐一说明

**节点 1：文章输入（输入节点）**

> 截图占位：该节点在画布上的样子及其属性面板。

- 作用：管线的起点，存放原始材料。
- 设置：在「内容」里粘贴文章全文；它对外提供一个 `text` 类型的出口，名字叫「文章文本」。

**节点 2：生成摘要（模型调用节点）**

> 截图占位：该节点属性面板，可见渠道 DeepSeek、模型 deepseek-flash、提示词模板。

- 作用：管线的加工车间。
- 设置：
  - 渠道：`DeepSeek`（内置渠道）；
  - 模型：`deepseek-flash`；
  - 提示词：

    ```
    请阅读以下文章，并生成一份结构清晰的 Markdown 摘要：
    {{input.text}}
    ```

    其中 `{{input.text}}` 会在运行时被自动替换为节点 1 传来的文章全文；
  - 输出格式：`md`，临时文件名 `summary.md`。

**节点 3：输出结果（输出节点）**

> 截图占位：该节点属性面板，格式 `md`，文件名 `article-summary.md`。

- 作用：管线的终点，把加工结果落盘保存。
- 设置：格式 `md`；最终文件名 `article-summary.md`，保存在 `output` 文件夹里。

### 两条连线

1. `文章输入` 的「文章文本」出口 → `生成摘要` 的「文章文本」入口：把原文喂给模型；
2. `生成摘要` 的「结果」出口 → `输出结果` 的「内容」入口：把模型生成的摘要交给输出节点保存。

### 整体示意

```
[ 文章输入 ] --文章文本--> [ 生成摘要 ] --结果--> [ 输出结果 ]
      （原文）            （DeepSeek 总结）      （article-summary.md）
```
