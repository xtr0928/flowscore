# 流谱 · FlowScore

开箱即用 AI 工作流精选导航站 —— 数据与投稿入口。

- 🌐 站点：**https://pipeline.zufe.com.cn/**
- ✍ 投稿：点上方 **Issues → 新建 Issue → ✍ 投稿工作流**，填写仓库链接即可
- 🤖 数据接口（供 AI 助手 / Agent 使用）：`https://pipeline.zufe.com.cn/api/workflows.json`
- 🔥 热度榜：https://pipeline.zufe.com.cn/hot.html （按 GitHub 星数增速）

## 收录标准

1. **真·开箱即用**：有可运行的路径（脚本 / 应用 / Docker / 工作流文件），不是纯教程、论文或模型权重
2. **与 AI 工作流相关**：能替人自动完成一段实际工作（处理文档、生成视频、采集数据、自动化操作……）
3. 开源且仓库可公开访问

## 判定流程

```
投稿 Issue → 服务器本地 Qwen3.8-27B 逐条读 README 判定
          → 通过 → 重新生成卡片站 → 收录上线
```

判定全程在本站服务器本地完成，不依赖任何云端 API。

## 与本站互动

- 想自己搭一条工作流？访问站点左侧的「工作流生成器」（可视化编排，导出配置文件交给任何 AI 助手即可落地）。
- 数据与站点的纠错、建议：直接开 Issue。
