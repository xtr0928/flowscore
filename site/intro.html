01流谱是什么

流谱把散落在 GitHub 里的可部署 AI 工作流筛出来、摆整齐：自动剪辑、批量文档、语音转写、数据采集、内容创作、科研计算……每一条都做过「部署实证」核查——仓库根目录确实存在能跑的入口（Dockerfile / docker-compose / package.json / requirements.txt / 一键脚本……），克隆下来即可使用。

判定与检索全部由服务器本地部署的模型完成——数据不出门、零云端费用。

02数据是怎么筛出来的

  • 多路扫描 GitHub 得到 18,000+ 候选池（多组关键词 × 按星分层 × 多语言，逐项去重）
  • 部署实证核查：逐仓库实查根目录的部署入口，达标者进入主列表——「存在可跑入口」是硬门槛
  • 本地模型批量打标：用途分类 × 形态 × 部署方式 × 模型运行 × 使用方式 × 类别，共六组标签，支持多选叠加筛选
  • 另每日记录星数快照，用于「热度榜」

03怎么用

01找 · 六面筛选
六组可折叠筛选项（用途分类置顶）：用途 × 形态 × 部署方式 × 模型运行 × 使用方式 × 类别，多选叠加、实时计数。
02问 · 语义找
用大白话描述需求（如「把会议录音变成纪要」），点「✨ 语义找」，本地 Qwen 从全站挑最合适的几条。
03抄 · agent 更快查找
侧边栏点「⚡ agent 更快查找」：输入一句话，直接列出项目地址清单——整段复制给任何 agent 就能开工。
04看 · 卡片直达
每张卡片标注星数、语言、部署方式、中英文简介与置信度；点「GitHub ↗」直达仓库。
05排 · 热度榜
把「最近涨星最快」的工作流拎出来，热度数据每天记录。
06造 · 工作流生成器
需要自己搭一条？打开画布拖拽编排节点（渠道 / 模型 / 提示词 / 输出格式），导出的配置交给任何 AI 助手即可落成可运行管线。

04投稿你的工作流

发现了好用的开源工作流，或者你自己写了一条？点侧边栏 ✍ 投稿，填一下仓库链接即可。投稿会进入同一条筛选流水线：部署实证核查 → 本地模型判定 → 通过后出现在主列表与「社区投稿」栏目。

05给 AI 助手 / Agent 的接口

整站开放只读接口，agent 可直接调用（说明见 llms.txt）：

  • GET /api/search?q=需求本地 Qwen 语义挑选，直接返回最合适的几条
  • GET /api/items分页查询：关键词 / 六组筛选 / 排序
  • GET /api/facets六组分面计数（留一法）
  • GET /api/stats站点统计

人用也不绕路：打开「⚡ agent 更快查找」，输入一句话，直接拿地址列表。

06关于

「有部署实证」仅代表仓库根目录存在部署入口（如 Dockerfile），不保证运行时无坑；收录不改写，所有项目遵循其原始开源协议。

流谱是一个个人维护的精选索引站：只收录、不改写。判定与查询均由服务器本地模型完成。
