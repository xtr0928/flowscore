输入一句需求（比如「把会议录音变成中文纪要」）→ 服务器上的本地 Qwen 从 12,000+ 条「有部署实证」的工作流里语义挑选 → 直接输出项目地址列表。给 agent 抄地址、给自己找轮子，都最快。

给 agent 直连（无需鉴权，只读）：
curl "https://pipeline.zufe.com.cn/api/search?q=你的需求&n=10" → JSON，items 里就是地址列表；
接口清单见 llms.txt · 全站浏览见 首页。
使用规范：查询 ≤200 字 · 每秒限 1 次 · 无状态单轮（不带上下文）· 只返回管线地址列表。
