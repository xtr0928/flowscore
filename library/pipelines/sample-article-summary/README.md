# 文章摘要（最小示例）

> 读一篇文章，产出摘要与标题 —— 学习流谱格式的最小完整例子

## 这份管线解决什么

输入一篇长文，输出「标题 + 三段式摘要」。

**它是拿来学格式的**：节点少、连线简单，但把流谱格式的核心概念都用到了 ——
编号（`seq`）、输入来自哪里（`inputs[].from`）、输出给谁（`outputs[].to`）、
节点要干什么（`does`）、设计意图（`note`）、以及一条**挂靠型注释**和一条**全局提示词**。

## 怎么跑

用流谱生成器打开 `pipeline.flow.json` 即可看到完整图；改掉 `config.provider` 指向你自己的端点就能跑。

## 前置条件

- 一个可用的 LLM 端点（默认写的是 DeepSeek）

## 注意事项

- 这是示例，**提示词是省略号**（`template: "……"`），直接跑不出有意义的摘要 —— 要自己填。
- `生成摘要` 节点**刻意不吃标题**，只看正文。上面挂的那条注释（`为什么不用标题`）解释了原因：标题党会带偏摘要。
- 想让摘要更短/更长，调 `n_sum` 的 `max_tokens`。
